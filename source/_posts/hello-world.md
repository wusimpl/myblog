欢迎使用 **Retro-Futurism** 主题！这是一套融合了复古美学与未来科技感的 Hexo 博客主题。

## 设计理念

这套主题的灵感来源于：

- 🎸 吉他效果器的精密旋钮
- 🎼 乐谱的优雅排版
- 💻 IDE 代码编辑器的结构美学

## 代码展示

```cpp
#include <iostream>
#include <vector>

class RetroFuturism {
public:
    void greet() {
        std::cout << "Hello, World!" << std::endl;
    }
    
    int calculate(int a, int b) {
        return a + b;
    }
};

int main() {
    RetroFuturism theme;
    theme.greet();
    return 0;
}
```
